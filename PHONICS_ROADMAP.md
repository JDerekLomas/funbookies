# FunBookies Phonics Learning Roadmap

A systematic, Direct Instruction-inspired approach to teaching reading from letter recognition through fluent decoding.

## Core Principles

### Direct Instruction Foundations
1. **Explicit Teaching** - Never assume; always model exactly what students should do
2. **Systematic Sequence** - Logical progression from simple to complex, prerequisite skills first
3. **Mastery Before Progress** - 80-90% accuracy before introducing new content
4. **High Response Rate** - Students actively responding every 10-15 seconds
5. **Immediate Feedback** - Correct errors instantly with model-lead-test
6. **Cumulative Review** - Continuously spiral back to reinforce previous learning

### Design Principles for Digital Activities
- **One skill per activity** - Don't mix learning objectives
- **Consistent UI patterns** - Same interaction = same meaning across activities
- **Audio-first for early learners** - Minimize text instructions
- **Generous timing** - Young children need processing time
- **Celebration without distraction** - Brief positive feedback, then move on
- **Error correction built-in** - Show correct answer, have child repeat

## Stage A: Pre-Reading Foundation (A1-A4)

**Goal:** Automatic letter-sound correspondence and basic phonemic awareness

### A1: Letter Recognition
**Skill:** Identify letters by name (uppercase and lowercase)

| Activity | Description | Status |
|----------|-------------|--------|
| Letter Names | See letter, hear name, say name | To Build |
| Letter Match | Match upper to lower case | To Build |
| Letter Find | Find target letter among distractors | To Build |

**Mastery Criteria:** Name all 26 letters (upper and lower) at 1 second per letter

### A2: Letter-Sound Correspondence
**Skill:** Associate each letter with its primary sound

| Activity | Description | Status |
|----------|-------------|--------|
| Sound Drill | See letter, say sound (flashcard style) | To Build |
| Sound Match | Hear sound, find the letter | To Build |
| Say the Sound | See letter, record saying sound | Exists |

**Mastery Criteria:** Produce correct sound for all 26 letters at 1 second per letter

**Teaching Sequence (DI-recommended order):**
```
Set 1: a, m, t, s, i, f, d, r, o, g
Set 2: l, h, u, c, b, n, k, v, e, w
Set 3: j, p, y, x, q, z
```

### A3: Phonemic Awareness (Oral)
**Skill:** Manipulate sounds without print

| Activity | Description | Status |
|----------|-------------|--------|
| First Sound | "What sound starts 'cat'?" | To Build |
| Last Sound | "What sound ends 'cat'?" | To Build |
| Sound Count | "How many sounds in 'cat'?" (tap for each) | To Build |
| Same Sound? | "Do 'cat' and 'cup' start the same?" | To Build |
| Oral Blend | Hear /c/ /a/ /t/, say "cat" | To Build |

**Mastery Criteria:** 80% accuracy on each task with CVC words

### A4: Sound-Symbol Integration
**Skill:** Connect phonemic awareness to written letters

| Activity | Description | Status |
|----------|-------------|--------|
| Sound Boxes | Drag letter tiles into Elkonin boxes | To Build |
| Sound Spelling | Hear sound, type/select the letter | To Build |
| Word Builder (Simple) | Build CVC words from sounds | Exists |

**Mastery Criteria:** Accurately segment and represent 3-sound words

## Stage B: Systematic Decoding (B1-B9)

**Goal:** Decode increasingly complex phonetic patterns

### B1-B2: CVC Words (Short Vowels)
**Skill:** Blend and read CVC words with all short vowels

| Activity | Description | Status |
|----------|-------------|--------|
| Blend It | Tap each sound, blend together | Exists |
| Voice Blend | Hear sounds, say the word | Exists |
| Word Builder | Construct words from letter tiles | Exists |
| Word Chains | cat → hat → hot → hop | To Build |
| Word Flash | Timed word reading | To Build |

**Phonics Sequence:**
- B1: Short a, i (cat, sit)
- B2: Short o, u, e (hot, cup, bed)

### B3-B4: Consonant Blends & Closed Syllables
**Skill:** Decode initial and final consonant blends

| Activity | Description | Status |
|----------|-------------|--------|
| Blend It | With blend segments (fr-o-g) | Exists |
| Chop It Up | Segment words with blends | Exists |

**Phonics Sequence:**
- B3: Initial blends (bl, cl, fl, fr, gr, st, sw, etc.)
- B4: Final blends & double letters (-ll, -ss, -ff, -ck)

### B5: Digraphs
**Skill:** Decode consonant digraphs as single sounds

| Activity | Description | Status |
|----------|-------------|--------|
| Digraph Drill | sh, ch, th, wh, ng recognition | To Build |
| Blend It | With digraph segments | Exists |

**Patterns:** sh, ch, th, wh, ng, ck

### B6: Silent E (CVCe)
**Skill:** Apply "magic e" rule for long vowels

| Activity | Description | Status |
|----------|-------------|--------|
| Magic E | See how e changes the vowel | To Build |
| Word Sort | CVC vs CVCe (hat/hate, bit/bite) | To Build |

**Patterns:** a_e, i_e, o_e, u_e

### B7: R-Controlled Vowels
**Skill:** Decode vowels modified by r

| Activity | Description | Status |
|----------|-------------|--------|
| Bossy R | ar, or, er/ir/ur patterns | To Build |

**Patterns:** ar, or, er, ir, ur

### B8: Vowel Teams
**Skill:** Decode common vowel digraphs

| Activity | Description | Status |
|----------|-------------|--------|
| Vowel Team Drill | ai/ay, ee/ea, oa/ow patterns | To Build |
| Word Sort | Sort by vowel team | To Build |

**Patterns:** ai, ay, ee, ea, oa, ow, oo, ou, oi, oy

### B9: Diphthongs & Complex Vowels
**Skill:** Decode remaining vowel patterns

**Patterns:** ow (cow), ou (out), oi (coin), oy (boy), oo (book/moon)

## Stage C: Multisyllable & Morphology (C1-C6)

**Goal:** Decode longer words and understand word structure

### C1: Compound Words
**Skill:** Read two-syllable compound words

| Activity | Description | Status |
|----------|-------------|--------|
| Compound Builder | Combine two words | To Build |

### C2: Inflectional Endings
**Skill:** Read words with -s, -es, -ed, -ing

| Activity | Description | Status |
|----------|-------------|--------|
| Ending Sort | Group by ending | To Build |

### C3-C4: Syllable Types
**Skill:** Decode using syllable division rules

**Syllable Types:**
- Closed (rab-bit)
- Open (ti-ger)
- VCe (cup-cake)
- Vowel Team (rai-sin)
- R-controlled (cor-ner)
- Consonant-le (ta-ble)

### C5-C6: Prefixes & Suffixes
**Skill:** Recognize common affixes

**Common Prefixes:** un-, re-, pre-, dis-
**Common Suffixes:** -ful, -less, -ment, -ness, -ly

## Assessment Strategy

### Placement
- **Letter Sounds Assessment** - Which letters are known?
- **Phonemic Awareness Screener** - Can they blend/segment?
- **Word Reading Probe** - Which patterns are decodable?

### Progress Monitoring
- Track accuracy per skill
- Track response time (automaticity)
- Flag items needing review
- Auto-adjust difficulty

### Mastery Gates
Before advancing to next stage:
- 90% accuracy on current skills
- Demonstrated on 3 consecutive sessions
- Cumulative review items still at 80%+
