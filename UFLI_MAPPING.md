# FunBookies to UFLI Alignment Mapping

## Overview

This document maps FunBookies' 28-level system (A0-D6) to UFLI Foundations' 128 lessons.

| Unit | Lessons | Focus |
|------|---------|-------|
| Getting Ready | A-J | Pre-reading concepts |
| Alphabet | 1-34 | Letter-sound correspondences |
| Alphabet Review | 35-41 | Short vowel CVC mastery |
| Digraphs | 42-53 | sh, ch, th, wh, ck, ng |
| VCe (Silent E) | 54-62 | Long vowel patterns |
| Longer Words | 63-68 | Multisyllable strategies |
| Ending Patterns | 69-76 | -tion, -sion, etc. |
| R-Controlled | 77-83 | ar, or, er, ir, ur |

| Low Frequency | 111-118 | Rare patterns |
| Additional Affixes | 119-128 | Advanced morphology |

## Sample UFLI Decodable Text by Lesson

### Lesson 8: "I Sit, I Tap"
```
I sit. I tap.
I sit and I tap.
I tap and I sit.
Pim and I sit.
Pim and I tap.
```
*Phonics focus: short i /ĭ/*
*Sight words: I, and*

### Lesson 10: "The Tan Van"
```
Sam has a tan van.
The tan van sat.
Can Sam fit in the van?
Sam can fit.
```
*Phonics focus: CVC with short a and i*

### Lesson 11: "Nan and Pap"
```
Nan and Pam sat.
Pam had a map.
Nan had a nap.
```
*Phonics focus: Nasalized A (am, an)*
