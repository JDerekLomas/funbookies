# Kiddom Curricula Features - Deep Research

## Overview

Kiddom is a K-12 digital curriculum platform that combines High-Quality Instructional Materials (HQIM) with AI-powered teaching tools. Their proprietary "Learning Intelligence Technology" (LIT) integrates curriculum, student data, and AI tools into a unified system.

**Key differentiator:** Unlike pure LMS platforms (Canvas, Schoology), Kiddom bundles actual curriculum content with the delivery platform.

## Teacher Tools

### Planner System
- **Pinterest-like interface** for organizing units, lessons, and resources
- **Drag-and-drop** assignments into Timeline
- **Cross-class accessibility** - use same curriculum across multiple classes
- **Master Curriculum** - shared with co-teachers for collaborative editing
- **70,000+ resources** in content library (Khan Academy, CK-12, ClassHook, Newsela)

### Timeline
- Visual calendar view of assigned work
- Drag assignments to individual students, groups, or whole class
- Due date management
- Student-facing view shows weekly assignments

### Playlists
- Curated collections of instructional materials
- 3-step peer review for quality assurance
- Can assign to individuals, groups, or whole class
- Supports differentiation pathways

### Curriculum Editing Suite
- **Edit in place** - modify any lesson or resource
- **Version control** - track changes, share versions
- **Contextualization** - adapt for distance learning, different contexts
- **District-level editing** - create protected master versions
- **Personal copies** - teachers can customize without affecting master

## AI Features (KiddomAI)

**Critical: All AI is teacher-facing only. Students never interact with AI directly.**

### Lesson Clipper
- Condenses lessons while preserving learning objectives
- Useful for substitute plans or accelerated groups
- Maintains instructional rigor in shortened form

### Practice Generator
- Creates differentiated practice sets automatically
- Generates scaffolded activities
- Produces supplemental materials on demand

### AI-Feedback
- Analyzes student responses
- Generates tailored, nuanced feedback for each submission
- Works on open-ended questions

### AI-Grading
- Auto-scores open-ended responses
- Provides recommended grades for teacher review
- Question-by-question feedback generation

### Smart Recommendations
- Just-in-time instructional guidance
- Lesson summaries to digest complex materials
- Suggests next steps based on student data

### Predictive Analytics
- Forecasts which students may struggle with upcoming content
- Enables proactive intervention

### AI-Powered Grouping
- Groups students by shared misconceptions
- Eliminates manual sorting for small-group instruction
- Based on assessment data patterns

### Privacy/Security
- Secure API with complete anonymization
- No personal student data in AI processing
- Nothing shared trains the underlying model

## Assessment & Reporting

### Standards Mastery Tracking
- Every standard aligned to assessments is tracked
- **Max Value Grading** - mastery = highest score achieved (not average)
- Real-time mastery dashboard updates as students complete work
- Multi-subject alignment (e.g., science text with ELA standards)

### Report Types
| Report | Description |
|--------|-------------|
| Class Mastery | Standards achieved across all students |
| Student Mastery | Individual student progress by standard |
| Standard Progress | Track how students progress toward mastery |
| Mastery Groups | Pie chart showing class distribution (exceeding, meeting, approaching) |
| Growth Over Time | Track how mastery groups change |

### Data Analysis
- Drill down from school-wide to individual student
- Parse by question and question type
- Identify reteach standards
- Identify grouping needs (heterogeneous/homogeneous)

### Export Options
- PDF standards-based reports
- PDF assignment reports
- CSV data exports
- Supports integration with district dashboards

## Competitive Analysis

### vs Canvas/Schoology (Pure LMS)
| Feature | Kiddom | Canvas/Schoology |
|---------|--------|------------------|
| Built-in HQIM curriculum | Yes | No |
| AI grading/feedback | Yes | Limited/No |
| Standards mastery (core) | Yes | Add-on |
| Free for teachers | Yes | No/Limited |
| Content authoring | Yes | Yes |
| LMS integrations | Yes | N/A |

### Kiddom Advantages
1. Curriculum + delivery in one platform
2. Teacher-facing AI saves grading time
3. Standards-based mastery is core, not add-on
4. Free tier for individual teachers
5. Pre-vetted HQIM content

### Kiddom Limitations
1. Limited to partner curricula (can't bring arbitrary content easily)
2. Pricing opaque for schools/districts
3. Fewer integrations than mature LMS platforms
4. Less customization flexibility than pure authoring tools

## Key Takeaways for ReadingPlanet

### Features to Consider
1. **Standards alignment** - Tag content to standards, track mastery
2. **AI feedback** - Teacher-facing only (privacy), human review layer
3. **Max Value Grading** - Mastery = best performance, not average
4. **Planner/Timeline** - Visual curriculum pacing tools
5. **Playlists** - Curated differentiation pathways
6. **Question variety** - 15+ types including drawing, video response
7. **Predictive analytics** - Forecast struggling students

### Pricing Strategy Insights
- Free for teachers builds adoption
- Quote-based for districts allows value-based pricing
- Tiered packages (Essentials → Achievement)

### Integration Strategy
- Rostering via Clever/ClassLink is table stakes
- Grade passback to existing LMS increases adoption
