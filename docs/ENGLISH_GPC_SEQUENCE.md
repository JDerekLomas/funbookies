# English GPC Sequence for FunBookies

Research-based grapheme-phoneme correspondence (GPC) sequence for systematic English phonics instruction.

---

## Guiding Principles

### 1. Frequency-Based Ordering

Like Kalulu's use of Manulex corpus for French, we prioritize GPCs based on:
- **Frequency in children's literature** - More common patterns first
- **Utility** - High-utility GPCs enable reading more words sooner
- **Decodability** - Simpler, more consistent patterns before complex ones

Research sources:
- [Phoneme-Grapheme Frequency Count (Hanna et al.)](https://journals.sagepub.com/doi/pdf/10.1207/s15548430jlr3601_5)
- [Corpus of English Children's Literature](https://scholarworks.umb.edu/masters_theses/870/)
- [UFLI Foundations Phonics Resources](https://ufli.education.ufl.edu/resources/teaching-resources/)

### 2. Alignment with Standards

Sequence aligns with:
- UK Letters and Sounds Phases 2-6
- Common Core RF.K-RF.2 standards
- Texas TEKS ELAR phonics standards

### 3. Decodability

Each lesson introduces GPCs that allow reading a meaningful number of decodable words using only previously taught patterns.

## Implementation Notes

### Word Selection Criteria

1. **Decodability**: Only use words that contain taught GPCs
2. **Frequency**: Prioritize high-frequency words
3. **Meaning**: Use words children know orally
4. **Interest**: Include engaging, concrete nouns

### Sentence Building

Each lesson should include decodable sentences using only:
- GPCs taught in current + previous lessons
- Introduced sight/tricky words

**Example (After Lesson 2)**:
- "Sam sat."
- "A man sat."
- "Pam did tap."

### Review Spiral

Following Kalulu's 70/30 rule:
- 70% of practice items from current lesson
- 30% from previous lessons (remediation-prioritized)

### Confusion Pairs to Monitor

Common confusions to track in confusion matrix:
- b/d (visual)
- p/q (visual)
- m/n (visual + auditory)
- s/sh (auditory)
- ch/sh (auditory)
- short vowels (a/e/i/o/u)
- f/v (auditory)
- th/f (auditory)
