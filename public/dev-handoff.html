Developer Notes

  • All activities are self-contained HTML files in public/activities/
  • Shared styles in public/styles/shared.css
  • Progress tracking via public/js/progress-tracker.js
  • Voice activities use the Web Speech API and/or OpenAI TTS
  • Audio files: letter sounds in public/activities/letter-sounds/, phonemes in public/audio/phonemes/
  • "New / Unshipped" activities exist on disk but aren't linked from the main activities index yet
  • Each Band pathway (band-a through band-d) has its own index.html that sequences activities for that level
