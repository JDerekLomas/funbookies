## Detailed Activity Analysis

### 1. letter-drill

**Kalulu Pattern**: Introduction / Look and Learn

**Purpose**: Establish basic letter-sound correspondences

**Skill Domain**:
- Alphabetic principle
- Letter recognition
- Phoneme production

**Mechanics**:
- Show letter
- Play phoneme sound
- Student identifies/produces sound

**Curriculum Alignment**:
- Common Core: RF.K.3a (know letter sounds)
- TEKS: K.2A (identify letter sounds)
- UK Letters and Sounds: Phase 2

**Integration Notes**:
- Should be first activity in any lesson introducing new GPCs
- Track per-letter remediation scores
- Difficulty: speed of presentation, number of letters

**Enhancement Opportunities**:
- Add letter tracing (like Kalulu)
- Add mnemonic images (A for Apple)
- Track confusion matrix for similar letters (b/d, p/q)

---

### 2. say-the-sound

**Kalulu Pattern**: Hear & Find (Syllable Games)

**Purpose**: Phoneme discrimination and grapheme recognition

**Skill Domain**:
- Phoneme awareness
- Grapheme recognition
- Auditory discrimination

**Mechanics**:
- Audio plays target phoneme
- Multiple graphemes displayed
- Student selects matching grapheme

**Curriculum Alignment**:
- Common Core: RF.K.2d (isolate phonemes)
- TEKS: K.2B (identify syllables and phonemes)
- UK Letters and Sounds: Phase 2-3

**Integration Notes**:
- Audio MUST play before response allowed
- Include replay button
- Auto-replay after timeout (15 seconds)
- On error: play selected phoneme, then replay target

**Difficulty Levels**:
1. Completely different sounds (s vs m)
2. Same category (all consonants)
3. Similar sounds (s vs sh)
4. Minimal pairs (b vs p)

**Enhancement Opportunities**:
- Add animation (like Kalulu's jellyfish)
- Moving targets at higher difficulties
- Timed challenges

---

### 3. sound-boxes (Elkonin Boxes)

**Kalulu Pattern**: Hear & Find + Word Building

**Purpose**: Phoneme segmentation and counting

**Skill Domain**:
- Phonemic awareness
- Segmenting
- Sound-to-box mapping

**Mechanics**:
- Word plays
- Student identifies number of phonemes
- Optionally: drag sounds to boxes

**Curriculum Alignment**:
- Common Core: RF.K.2d (segment words into phonemes)
- TEKS: K.2B (identify syllables in spoken words)
- UK Letters and Sounds: Phase 2-3

**Integration Notes**:
- Visual boxes represent phoneme slots
- Critical for spelling development
- Track difficulty by word length

**Difficulty Levels**:
1. CVC words (3 boxes)
2. CVCC/CCVC words (4 boxes)
3. CCVCC words (5 boxes)
4. Multi-syllable words

---

### 4. blend-it

**Kalulu Pattern**: Word Building (Oral)

**Purpose**: Oral blending of phonemes into words

**Skill Domain**:
- Blending
- Phoneme synthesis
- Word recognition

**Mechanics**:
- Individual phonemes play in sequence
- Student blends mentally
- Student identifies/selects whole word

**Curriculum Alignment**:
- Common Core: RF.K.2c (blend phonemes into words)
- TEKS: K.2C (blend spoken phonemes)
- UK Letters and Sounds: Phase 2-3

**Integration Notes**:
- Pure auditory processing (no written letters initially)
- Speed of phoneme presentation = difficulty
- Can progress to showing letters

**Difficulty Levels**:
1. Slow, 2-phoneme words
2. Normal speed, CVC words
3. Fast, CCVC/CVCC words
4. Very fast, complex words

---

### 5. voice-blend

**Kalulu Pattern**: Word Building (Oral + Voice Recognition)

**Purpose**: Oral blending with speech production

**Skill Domain**:
- Blending
- Pronunciation
- Speech production

**Mechanics**:
- Phonemes displayed
- Student speaks blended word
- Voice recognition validates

**Curriculum Alignment**:
- Common Core: RF.K.2c (blend phonemes)
- TEKS: K.2C (blend spoken phonemes)
- UK Letters and Sounds: Phase 2-3

**Integration Notes**:

### 6. word-builder

**Kalulu Pattern**: Word Building (like Turtles, Ants, Penguin)

**Purpose**: Build words by selecting GPCs in order

**Skill Domain**:
- Blending (written)
- Spelling
- Sequential processing

**Mechanics**:
- Word plays
- GPCs displayed as options
- Student selects GPCs left-to-right to spell word

**Curriculum Alignment**:
- Common Core: RF.1.2c (isolate and pronounce phonemes)
- TEKS: 1.2A (decode words in isolation)
- UK Letters and Sounds: Phase 3-4

**Integration Notes**:
- **KEY KALULU PATTERN**: One GPC at a time, left to right
- Error on any GPC = redo that position
- Shows which GPCs are already placed
- Track remediation per GPC

**Difficulty Levels**:
1. CVC words, 3 options per GPC
2. CVCC words, 4 options per GPC
3. CCVC words, 5 options per GPC
4. Complex words, similar distractors (sh/ch)

**Enhancement Opportunities**:
- Add Kalulu-style game wrapper (swimming animals)
- Progressive time pressure
- Bonus for no errors

---

### 7. word-chains

**Kalulu Pattern**: Word Building (Phoneme Manipulation)

**Purpose**: Change one phoneme to make new word

**Skill Domain**:
- Phoneme manipulation
- Minimal pair awareness
- Spelling patterns

**Mechanics**:
- Start with word (cat)
- Change one letter to make new word (cat → hat)
- Chain continues (hat → hot → hop...)

**Curriculum Alignment**:
- Common Core: RF.1.2c (distinguish phonemes)
- TEKS: 1.2B (demonstrate phonological awareness)
- UK Letters and Sounds: Phase 4

**Integration Notes**:
- Excellent for revealing phoneme-grapheme relationships
- Track which positions are harder (initial vs final)
- Use confusion matrix to identify problematic pairs

**Difficulty Levels**:
1. Change final consonant
2. Change initial consonant
3. Change medial vowel
4. Mixed positions

**Curriculum Alignment**:
- Common Core: RF.K.2a (recognize rhyming words)
- TEKS: K.2E (recognize rhyming words)
- UK Letters and Sounds: Phase 2-3

**Integration Notes**:
- Builds on rhyme awareness
- Supports decoding by analogy
- Group related words in lessons

### 11. sight-words

**Kalulu Pattern**: Lexical Decision (like Fish Game)

**Purpose**: Automatic recognition of high-frequency words

**Skill Domain**:
- Sight word recognition
- Automaticity
- Reading fluency

**Mechanics**:
- Words appear
- Student identifies if knows word
- Practice with flashcard-style repetition

**Curriculum Alignment**:
- Common Core: RF.K.3c (read common sight words)
- TEKS: K.3B (read common high-frequency words)
- UK Letters and Sounds: Tricky Words (all phases)

**Integration Notes**:
- Include both decodable and irregular words
- Track per-word mastery
- Spaced repetition crucial here
- Band levels: A1-C6 already implemented

**Enhancement Opportunities**:
- Add real vs pseudoword discrimination
- Speed challenges for automaticity
- Context sentences for meaning

## Activity Sequencing per Lesson

### Recommended Order

```
1. Introduction (if new GPCs)
   └── letter-drill: Learn new letter-sounds

2. Phoneme Practice
   ├── say-the-sound: Hear → find grapheme
   └── chop-it-up: Segment sounds

3. Blending Practice
   ├── blend-it: Oral blending
   ├── voice-blend: Spoken blending
   └── word-builder: Build words with GPCs

4. Pattern Practice
   ├── word-chains: Phoneme manipulation
   └── word-families: Rime patterns

5. Fluency Practice
   ├── sight-words: Automatic recognition
   ├── read-aloud: Connected text
   └── sentence-scramble: Sentence building
```

### Activity Selection by Skill Gap

| If struggling with... | Use activities... |
|-----------------------|-------------------|
| Letter-sound knowledge | letter-drill, say-the-sound |
| Blending | blend-it, voice-blend, word-builder |
| Segmenting | sound-boxes, chop-it-up |
| Phoneme manipulation | word-chains, word-families |
| Sight words | sight-words (spaced repetition) |
| Fluency | read-aloud, sentence-scramble |
